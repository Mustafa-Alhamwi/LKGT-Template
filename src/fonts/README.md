# خطوط الهوية (اختياري)

البرنامج يكتشف **Araboto** و **HP Simplified** المثبتة على جهازك تلقائياً.

إذا أردت تضمين الخطوط مع المشروع (مثلاً لتشغيله على جهاز آخر)، انسخ ملفاتها هنا
(`.ttf` أو `.otf`) — سيتعرف عليها البرنامج تلقائياً من داخل الملف (الاسم والوزن):

```
src/fonts/Araboto Thin 400.ttf
src/fonts/Araboto Light 400.ttf
src/fonts/Araboto Normal 400.ttf
src/fonts/Araboto Medium 400.ttf
src/fonts/Araboto Bold 400.ttf
src/fonts/Araboto Black 400.ttf
src/fonts/HPSimplified_Lt.ttf
src/fonts/HPSimplified_Rg.ttf
src/fonts/HPSimplified_Bd.ttf
```

> تنبيه: هذه خطوط مرخّصة — لا تنشر المستودع للعامة إذا وضعتها هنا.
